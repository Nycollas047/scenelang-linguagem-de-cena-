# SceneLang Assistant

SceneLang Assistant é um plugin comunitário de Nycollas Augusto para usar IA com SceneLang. Ele ajuda a transformar briefs visuais em YAML SceneLang, explica a linguagem e fundamenta revisões no código-fonte, nos testes, nos exemplos e na documentação públicos do projeto.

O plugin é um conjunto de instruções para uma plataforma de IA. Não inclui servidor SceneLang e não executa o parser, validador, compilador ou verificadores de imagem. As cenas e explicações geradas são sugestões; para validação oficial, use a CLI do projeto.
