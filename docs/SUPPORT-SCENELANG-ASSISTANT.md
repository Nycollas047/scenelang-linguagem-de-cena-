# Ajuda comunitária — SceneLang Assistant

SceneLang Assistant estrutura ideias visuais como cenas YAML SceneLang e explica o formato usando o código, a gramática, os testes e a documentação públicos do projeto.

## Autoatendimento, sem suporte individual

Este projeto não oferece suporte individual nem garante resposta a pedidos. Para aprender e resolver dúvidas, consulte o [README](https://github.com/Nycollas047/scenelang-linguagem-de-cena-#readme-ov-file), a [referência da linguagem](https://github.com/Nycollas047/scenelang-linguagem-de-cena-/blob/main/docs/LANGUAGE.md) e os exemplos no repositório. Você também pode usar uma IA de sua preferência com o código e a documentação públicos do SceneLang.

Defeitos reproduzíveis no código do SceneLang podem ser registrados no [rastreador público de issues](https://github.com/Nycollas047/scenelang-linguagem-de-cena-/issues). É necessário entrar no GitHub para abrir uma issue. Issues são relatórios comunitários; não há promessa de triagem ou resposta.

O SceneLang Assistant não executa o validador do repositório nem envia conteúdo para um servidor próprio. Para validação oficial, instale o SceneLang e execute `scenelang validate arquivo.yaml`.

Veja também: [política de privacidade](PRIVACY-SCENELANG-ASSISTANT.md) e [termos de uso](TERMS-SCENELANG-ASSISTANT.md).
